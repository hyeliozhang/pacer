# Data license note

The default benchmark data are generated by the artifact scripts and are distributed as generated experimental outputs for reproducibility. Public-feature checks use small public datasets available through scikit-learn and the bundled UCI/UCSD Pendigits sta16 text files already included in this artifact. Policy, deletion, tenant, and provenance columns for public-feature checks are deterministic database metadata generated by the artifact; they are not claimed to be native labels from the public datasets.
