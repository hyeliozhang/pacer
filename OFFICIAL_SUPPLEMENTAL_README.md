# Official Supplemental Material

This repository is the reviewer-facing PACER supplement. It contains code, data-generation scripts, result summaries, figures/tables, gates, and reproduction instructions for the claims in the paper.

ICDE supplemental material should be hosted through a standard, openly accessible service with a clear privacy policy, such as an anonymous/public repository or file service. Do not use a personal webpage or tracking service that can identify reviewers.

The package also includes an optional Dockerfile and environment lock for reviewers who want a clean CPU-only reproduction environment.
